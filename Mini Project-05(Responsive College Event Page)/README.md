The Alliance University College Event Webpage is a frontend web development project created to demonstrate the use of HTML5, CSS3, and responsive web design.
The webpage is designed to work smoothly across desktop, tablet, and mobile devices using CSS media queries.

✨ Features
- 📱 Responsive Navigation Bar
  - Navigation links to different sections
  - Mobile-friendly hamburger menu
- 🎉 Event Banner
  - Event/fest name
  - Event date
  - Register button
- 🚀 Event Highlights
  - Hackathon
  - Workshops
  - Tech Talks
  - Competitions
  - Venue information
- 📅 3-Day Event Schedule
  - Organized timetable
  - Events displayed according to date and time
- 🎤 Speaker Section
  - Guest speaker cards
  - Speaker names
  - Designations
  - Short biographies
- 📝 Registration Form
  - Name
  - Email
  - Phone
  - College
  - Branch
  - Event selection
- 📞 Contact Section
  - University address
  - Email
  - Phone number
  - Message/contact form
- 📐 Responsive Design
  - Desktop layout
  - Tablet layout
  - Mobile layout
  - Media queries for 768px and 480px
🛠️ Technologies Used
- HTML5
- CSS3
- Responsive Web Design
- CSS Media Queries
