This project demonstrates the development of a modern, responsive portfolio website using CSS Grid, CSS transitions, hover effects, and animations.
The portfolio focuses on my interests and skills in Data Science, Data Analytics, Python, SQL, Pandas, Power BI, and Data Visualization. The website provides a clean and professional interface that works across desktop, tablet, and mobile devices.
✨ Features
- Responsive navigation bar
- Hero/Introduction section
- About Me section
- Skills section
- Project showcase
- Contact form
- CSS Grid-based layout
- Responsive design for different screen sizes
- Hover effects on cards and buttons
- CSS transitions
- Entry animations
- Animated skill progress bars
- Modern blue color theme
- Mobile-friendly layout
🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and layout
- CSS Grid – Responsive page structure
- CSS Flexbox – Component alignment
- CSS Animations – Entry and floating animations
- CSS Transitions – Smooth hover interactions
- Google Fonts – Poppins typography
